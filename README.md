
# 💚 Umeed Foundation

### Small Acts. Big Changes.

Umeed Foundation is a responsive NGO and social welfare website designed to promote social causes, showcase community initiatives, and encourage people to donate and volunteer.

## 🌟 Features

- 🏠 **Home Page** – A welcoming landing page with a background image.
- ℹ️ **About Us** – Introduction and impact statistics.
- 📚 **Our Causes** – Education, food support, healthcare, and environment.
- 📸 **Our Previous Work** – Image gallery showcasing social welfare activities.
- 💚 **Donation Section** – Interactive donation amount selection.
- 🙋 **Volunteer Form** – A form for people interested in volunteering.
- 📱 **Responsive Design** – Works on desktop and mobile screens.

## 🛠️ Technologies Used

- HTML5 – Website structure
- CSS3 – Styling, layouts, and responsive design
- JavaScript – Donation buttons and volunteer form interactions

## 🚀 How to Run

1. Download or clone this repository.
2. Open the project folder.
3. Open `index.html` in your browser.
4. Explore the different sections and interactive features.

You can also run the website using the **Live Server** extension in Visual Studio Code.

## 🎯 Project Objective

The objective of this project is to create a simple, user-friendly platform that spreads awareness about social welfare initiatives and motivates people to contribute to meaningful causes.

## 🔮 Future Improvements

- Online payment gateway integration
- Backend database for volunteer registrations
- Admin dashboard to manage campaigns
- Real-time donation tracking
- Contact form and social media integration

## ⚠️ Note

This is an educational frontend project. Donation buttons display demo messages and do not process real payments. The volunteer form does not store submitted information. Gallery images are illustrative and can be replaced with actual foundation photographs.
